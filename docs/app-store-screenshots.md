# App Store Screenshot Plan

Use 6.7-inch iPhone screenshots first. If App Store Connect asks for more sizes, reuse the same composition.

## Screenshot Set

1. Draft Board
   Overlay: `Build Your World Cup XI`
   Show: coin draw screen with formation, manager, squad cards, and pitch.

2. Player Pick
   Overlay: `Pick Real Positions`
   Show: player selection sheet with ratings and locked/unlocked positions.

3. Live Match
   Overlay: `Simulate Every Match`
   Show: live score, clock, event feed with goals/cards.

4. Tournament Run
   Overlay: `Survive Groups & Knockouts`
   Show: previous matches list and group standings.

5. Match Details
   Overlay: `Tap For Key Moments`
   Show: an expanded previous match with goals, yellow cards, red cards, penalties.

6. Result Card
   Overlay: `Share Your Run`
   Show: final result popup with W-D-L record and share card.

## Overlay Style

- Keep text short, max 4 words.
- Use white or bright yellow text over a dark translucent band.
- Put overlay near the top, away from the iPhone status area.
- Do not cover the score, pitch positions, or main action button.
